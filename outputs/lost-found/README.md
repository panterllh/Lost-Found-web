# Lost & Found

A standalone bilingual Lost & Found web app.

## Run

Open `index.html` directly, or serve the folder with Node:

```bash
node start-server.js
```

Then visit `http://localhost:4173`.

## Notes

- Data persists in `localStorage`.
- Use the demo account button in the navigation bar to switch between users and test authorization.
- Uploaded images are stored in the browser as data URLs.
- Listings, messages, notifications, reports, ownership checks, matches, and recovered history are all functional locally.
